Instellingen

Local REST API (desktop Obsidian), Ignis direct, of Docker-proxy.

Local REST: Obsidian moet open staan met plugin Local REST API. Key kopieer je uit de plugin-instellingen. HTTPS (27124) gebruikt een self-signed certificaat — open die URL eenmalig in Chrome en vertrouw het, of schakel HTTP in (27123).

REST proxy: Docker nginx proxy't /obsidian-rest/ naar je PC (OBSIDIAN_REST_UPSTREAM).

Ignis: /api/fs/writeFile zoals voorheen.
