Ignis Quick Capture

Sla een notitie op in je Obsidian-vault via de Ignis API — zonder Obsidian te openen.

Instellingen
CORS: pagina op een andere server

Ignis stuurt standaard geen Access-Control-Allow-Origin-headers. Een browser blokkeert dan directe calls vanaf een andere origin. Dat los je op server-side op (niet in JavaScript alleen).

Optie A — proxy op de server van deze pagina (aanbevolen)

Zet API-verbinding op Via proxy en configureer je webserver zodat /ignis-api/ doorstuurt naar Ignis /api/:

Nginx:

location /ignis-api/ {
    proxy_pass https://10.5.0.134/api/;
    proxy_ssl_verify off;
    proxy_set_header Host $host;
}

Caddy:

handle_path /ignis-api/* {
    rewrite * /api{path}
    reverse_proxy https://10.5.0.134
}

Optie B — CORS vóór Ignis

Op de reverse proxy van Ignis: voeg voor /api/ headers toe met jouw capture-origin (exacte URL, geen * als je cookies gebruikt). Handel OPTIONS af met 204. Daarna werkt modus Rechtstreeks naar Ignis.
