Vault Quick Capture

Sla notities op in je Obsidian-vault via SSH/SFTP op de server — geen Ignis API of CORS nodig. Start de Node-server (npm start) en open deze pagina via die server.

Instellingen (browser)

SSH-host, gebruiker, key en VAULT_PATH staan in .env op de server (zie .env.example). Typisch Ignis-pad op de host: .../vaults/My Vault.
